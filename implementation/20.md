# 20.5 AI Agent Responsibilities

The AI Agent is the orchestrator.

It should:

```
Understand Intent

↓

Choose Tools

↓

Collect Data

↓

Build Prompt

↓

Call LLM

↓

Return Response
```

The agent coordinates the workflow rather than performing all tasks itself.

---

# 20.6 Tool Selection

Different questions require different tools.

Example:

```
How many Medium problems?

↓

SQL
```

```
Similar to Two Sum

↓

Retriever
```

```
Weak topics

↓

Analytics
```

The agent should avoid unnecessary operations.

# 20.13 Context Assembly

```

Problem B

Problem C
```

# 20.14 Calling the LLM

```
↓

↓

↓

```
