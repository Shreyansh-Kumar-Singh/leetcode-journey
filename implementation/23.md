# Section 23 — Building an Intelligent Recommendation Engine

> **Objective:** Transform your LeetCode Visualizer from a dashboard into an AI Coding Coach that can analyze your history, identify weaknesses, prioritize topics, and generate personalized study plans.

---

# 23.1 Why a Recommendation Engine?

Most LeetCode dashboards only answer questions like:

- How many problems have I solved?
- What is my acceptance rate?
- Which topics have I practiced?

Useful—but passive.

An AI coach should answer:

- What should I solve next?
- Which topics am I forgetting?
- Which concepts am I weakest at?
- Am I interview-ready?
- What should I revise today?

Instead of visualization, we move toward **decision support**.

# 23.12 Topic Score

Example formula:

```text

0.5 × Solve Count
```

# 23.14 Recency Score

Recent practice matters.

Example:

```
Solved yesterday

↓

High recency score
```

```
Solved 400 days ago

↓

Low recency score
```

Recent topics generally require less immediate revision.

# 23.15 Forgetting Curve

Human memory fades over time.

Simple approximation:

```
Time Since Solve

↓

Revision Priority
```

Example:

| Days Since Solve | Priority |
|------------------|----------|
| 3 | Low |
| 30 | Medium |
| 90 | High |
| 180 | Very High |

# 23.35 AI Integration

The recommendation engine should generate structured data.

The LLM's job is to explain it.

Bad:

```
LLM invents recommendations.
```

Good:

```
Recommendation Engine

↓

Structured Results

↓

LLM Explanation
```

This reduces hallucinations and keeps recommendations reproducible.
